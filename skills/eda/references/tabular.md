# 表形式のデータを見る

行と列で観測・属性を扱うときに読む。イベントの構造や予測用途の制約は、EDAの入口で選んだ参照と組み合わせる。

## 列の役割と観測単位を確かめる

キー、属性、時刻、計測値、結果、集計済みの値を区別する。数値型でも識別番号やカテゴリなら連続量として扱わない。
値の単位・有効範囲・欠測コード・集計窓を確認し、ゼロ、欠測、未発生、対象外を区別する。
列名だけで意味を決めず、データ定義と生成手順を照合する。

行数、キーの一意性、対象数、期間、主要区分の件数を押さえる。重複は1行の定義に照らして判断し、
同じ対象の反復記録を削除しない。複数表では、結合前後の行数・キー数・未結合件数と想定する多重度を確認する。
列が多い場合は、定義と関心から概観対象を選び、その範囲と未確認項目を残す。

## 問いに合う方法を選ぶ

| 確かめたいこと | 方法の候補 | 解釈で確認すること |
|---|---|---|
| 典型的な値とばらつき、裾・複数の山 | 分位点、ヒストグラム、経験累積分布、箱ひげ図 | 件数・単位・軸・ビン。平均だけで異なる形を同一視しない |
| 区分の偏りや希少な値 | 件数・割合、頻度順の表示 | 分母、未知カテゴリ、まとめた区分。IDの頻度は対象ごとの観測回数として読む |
| 欠測や特殊値の偏り | 列別・主要条件別の件数と率 | 記録されなかった行は列の欠測率に含まれない。データ源や収集時期の差も調べる |
| 群ごとの違い | 同じ尺度の分布図、分位点・率の比較 | 群の件数、期間、構成、重み。全体と群内の傾向を区別する |
| 項目間の関係 | 散布図、クロス集計、関係に合う相関の要約 | 非線形性、極端値、群の混在、観測の依存。相関係数だけで関係を説明し切らない |

全組み合わせを自動的に掘り下げず、既知の観測と今回の関心に結びつく見方を計画時に選ぶ。
表示方法・集約粒度・少数の値への依存が予想される場合は、別の表現や条件での確認も計画に含める。
結果を見て初めて追加確認が必要だと分かった場合は、今回の限界と次の探索候補として返す。
極端な値は仕様や元記録に照合し、値が大きい・少ないことだけで誤りや除外対象としない。

## 比較と標本の範囲を示す

比較では母数、対象・期間、欠測の除外、集約単位を揃えるか、その違いを説明する。
割合は分子・分母と件数を併記し、分母がない値をゼロへ置き換えない。
一部の事例を読んだ場合は抽出方法と件数を残し、その事例だけで頻度を推定しない。
抽出データしかない場合は抽出方法と観測できない範囲を示し、全体の頻度へ一般化できるかを区別する。
